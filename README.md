# MauriLink — Site vitrine

Site vitrine de **MauriLink**, entreprise mauritanienne de solutions numériques basée à Nouakchott. Développé avec React 18 et Vite, il présente les plateformes conçues et maintenues par l'équipe MauriLink.

## Solutions présentées

| Solution | Description | Démo |
| --- | --- | --- |
| **PoolPay — Digital Banking** | Banque digitale / banque en ligne : gestion de comptes et paiements entièrement dématérialisés. | [frontend-digital-banking.vercel.app](https://frontend-digital-banking.vercel.app/) |
| **Agharina** | Plateforme immobilière (location, achat, vente) en Mauritanie, avec réservation en ligne. | [agharina-frontend-client.vercel.app](https://agharina-frontend-client.vercel.app/) |
| **Newat** | Cours en ligne et suivi de progression pour les étudiants. | [newat.ai](https://www.newat.ai/login) |
| **MauriLink — Appels d'offres & emploi** | Publication d'appels d'offres et d'offres d'emploi, candidature et suivi de dossier en ligne. | [maurilink.site](https://www.maurilink.site/) |

## Stack technique

- [React 18](https://react.dev/)
- [Vite 5](https://vitejs.dev/)

## Démarrer le projet

```bash
npm install
npm run dev      # serveur de développement
npm run build    # build de production
npm run preview  # prévisualiser le build
```
